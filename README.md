# 🏗️ Retail Data Lakehouse

A modern Data Engineering project that demonstrates how to build a Retail Data Lakehouse using the Bronze, Silver, and Gold architecture.

This project processes retail sales data, performs data quality checks, transforms raw datasets into analytics-ready tables, and provides interactive dashboards for business insights.

---

## 🚀 Tech Stack

- Python
- PySpark
- DuckDB
- Pandas
- Parquet
- Streamlit
- Plotly
